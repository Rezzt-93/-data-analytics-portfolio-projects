# Data Source


This project uses the 'Himalayan Expeditions' dataset published on Kaggle:

https://www.kaggle.com/datasets/siddharth0935/himalayan-expeditions/data

The dataset contains records for more than 11,000 Himalayan expeditions covering the period from 1905 to 2024.


## Files Used


The Power BI analysis was built using:
- `peaks.csv`
- `exped.csv`
- `members.csv`


## Data Version

The version used in this project contains records through June 2024.
Therefore, 2024 is treated as a partial year in the report.
