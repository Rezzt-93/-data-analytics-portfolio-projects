# Data Source
 
This project uses the **SuperStore Sales Analytics** dataset published on Kaggle.
 
- **Dataset:** SuperStore Sales Analytics
- **Publisher:** Đào Minh Thuận
- **Source:** https://www.kaggle.com/datasets/thuandao/superstore-sales-analytics
- **License:** Apache License 2.0
- **License text:** https://www.apache.org/licenses/LICENSE-2.0
 
## Included File
 
- `SuperStoreOrders.csv`
 
The CSV file is included in its original downloaded form. Data cleaning, type conversion, validation, key creation, and analytical modelling were performed in Power Query and Power BI.
 
## Dataset Scope
 
The source file contains transactional sales data covering the period from January 1, 2011, to December 31, 2014.
 
The dataset includes information about:
 
- Orders and shipping
- Customers and customer segments
- Products and product categories
- Markets, regions, and countries
- Sales, quantity, discounts, profit, and shipping costs
